| البند | القيمة |
|---|---|
| أعدّها | `qa-launch-specialist` |
| التاريخ | 2026-11-12 |
| الحالة | جاهزة مسبقاً؛ لم يُنفَّذ شيء بعد (المتجر لم يُبنَ) |
| خطة الاختبار | `06-qa/test-plan.md` |

**رموز الأجهزة** (التفصيل في `test-plan.md` القسم 3): **M1** iPhone Safari · **M2** Android Chrome بعرض 360 · **T1** تابلت 768 · **D1** حاسوب Chrome بعرض 1280 · **D2** Edge · **D3** Mac Safari · **ADM** لوحة سلة (يسجّل العميل الدخول) · **FILE** فحص ملف · **الكل** = M1 + M2 + D1 على الأقل.

**الأولوية** = خطورة الخطأ لو فشلت الحالة: حرج / عالٍ / متوسط / منخفض.

**عمود "النتيجة":** يُكتب ✔ نجح، أو ✘ مع رقم الخطأ (BUG-xxx)، أو "لم يُختبر" مع السبب.

> القيم التجارية (الأسعار، الرسوم، الحدود، الأوقات) **لم تُستلم بعد**. أينما ظهر "حسب `shipping-payment.md`" أو "حسب `products.csv`" تُكتب القيمة الفعلية في الحالة قبل التنفيذ، ولا تُفترض.
