# الهياكل (Wireframes) — الصفحة الرئيسية وصفحة التصنيف وصفحة المنتج

> نموذج تجريبي لمتجر "دار الحلا" (اسم توضيحي). التنفيذ الفعلي: `preview/index.html` و`preview/category.html` و`preview/product.html`.
> رحلة الشراء في النموذج: الرئيسية ← التصنيف (من القائمة أو التذييل) ← المنتج (بطاقة بوكس المعمول) ← والعودة بمسار التصفح.
> الرسوم هنا للجوال (360px) لأن أغلب زيارات متاجر الحلويات في السعودية تأتي من الجوال وإعلانات سناب وتيك توك. فروق الحاسوب مذكورة تحت كل رسم.

---

## المبدأ العام: ثلاثة أسئلة يسألها الزائر بالترتيب

1. **"هل هذا المكان يناسبني؟"** ← الهوية، والبانر، والتوصيل نفس اليوم (أول 3 ثوانٍ).
2. **"ماذا أشتري؟"** ← الأكثر طلباً، ثم المناسبات.
3. **"هل أثق بهم؟"** ← المزايا، والدفع الآمن، والآراء، والأسئلة الشائعة.

ترتيب الأقسام يجيب عن هذه الأسئلة بالترتيب نفسه. **كل قسم ينتهي بطريق للشراء** حتى لا يضطر الزائر للعودة للأعلى.

**على الحاسوب (1024px فأكثر):**
- الرأس صف واحد: الشعار ثم البحث في الوسط ثم الحساب والسلة. والقائمة صف أفقي تحته، فلا قائمة همبرغر.
- البانر عمودان: النص يميناً والرسم يساراً.
- المنتجات 3 أعمدة، والمناسبات 6 في صف، والمزايا 4، والآراء 3، والتذييل 4 أعمدة.

### لماذا هذا الترتيب يرفع التحويل؟

| # | القسم | السبب |
|---|---|---|
| 1 | **شريط "توصيل نفس اليوم"** | أكبر سبب لترك متاجر الحلويات هو الشك في وصول الطلب في الوقت. وضع الوعد في أول سطر يزيل الاعتراض قبل أن يتكوّن، وهو مفيد خاصة لزائر الإعلان المستعجل لمناسبة اليوم |
| 2 | **رأس ثابت فيه بحث ظاهر وسلة بعداد** | من يعرف ما يريد ("معمول") يصل إليه بنقرة. والسلة مرئية دائماً تذكّر بما أُضيف |
| 3 | **بانر بعنوان فائدة وزر واحد بارز** | العنوان يجمع العاطفة (المناسبة) والوعد (اليوم). وزر CTA الأخضر هو الوحيد بهذا اللون فلا يتشتت الانتباه. والزر الثاني (محدّد) يخدم من يبحث عن هدية |
| 4 | **الأكثر طلباً قبل التصنيفات** | الدليل الاجتماعي يختصر الحيرة: "الناس يشترون هذا". وزر "أضف للسلة" داخل البطاقة يجعل الشراء ممكناً دون فتح صفحة المنتج |
| 5 | **المناسبات** | الحلويات في السعودية تُشترى غالباً **لمناسبة** (عيد، زواج، مولود، تخرج، يوم وطني، هدايا شركات). التصنيف بالمناسبة يطابق نية الزائر أكثر من التصنيف بنوع الحلى، ويفتح باب طلبات الشركات الكبيرة |
| 6 | **المزايا** | تأتي بعد أن اهتم الزائر بمنتج، فتجيب عن "لماذا من هنا؟": طازج، وتغليف، وموعد، ودفع آمن. شعارات مدى وApple Pay وتابي تطمئن المتردد وتلمّح للتقسيط |
| 7 | **الآراء** | الثقة قبل القرار. ثلاثة آراء قصيرة مرتبطة بالمناسبات تكفي |
| 8 | **الأسئلة الشائعة** | تجيب عن آخر الاعتراضات (الموعد، والإهداء، والدفع، والصلاحية، والشركات)، وتقلل رسائل واتساب المتكررة |
| 9 | **تذييل فيه السياسات والسجل والدفع** | يطلبه المشتري الحذر ومنصات الدفع، ويرفع الثقة. السجل التجاري والرقم الضريبي خانات فارغة حتى يرسلها العميل |
| — | **زر واتساب عائم** | قناة البيع الأولى للهدايا الكبيرة وطلبات الشركات في السوق السعودي |

## 2. صفحة التصنيف (المعمول والتمور)

```
┌─────────────────────────────────┐
│ (الرأس كما في الرئيسية)         │
├─────────────────────────────────┤
│ الرئيسية / المعمول والتمور      │ مسار التصفح
├─────────────────────────────────┤
│ المعمول والتمور          (H1)   │ 1. العنوان والفقرة التعريفية
│ بوكسات معمول تُخبز صباح يوم...  │    سطران فقط في الجوال
│ ...والجوز، وتمور محشية…         │    (النص كاملاً في HTML)
│ اقرأ المزيد                     │
├─────────────────────────────────┤
│ [⚙ تصفية (2)]   [⇅ ترتيب      ] │ 2. شريط الأدوات: زران متساويان
│                 [ الأكثر طلباً ] │    "ترتيب" قائمة select حقيقية
│ عرض 5 من 8 منتجات               │    والعدد يتحدث مع كل فلتر
│ [العيد ✕] [يصلح هدية ✕] مسح الكل│ 3. الفلاتر المفعّلة (تُزال بنقرة)
├─────────────────────────────────┤
│ ┌──────┐ ┌──────┐               │ 4. الشبكة (8 منتجات)
│ │ صورة │ │ صورة │               │    عمودان في الجوال
│ │ اسم  │ │ اسم  │               │    نفس بطاقة الرئيسية + سطر
│ │ ★    │ │ ★    │               │    "توصيل اليوم" أو "يُطلب قبل يوم"
│ │🚚اليوم│ │🚚اليوم│               │
│ │ سعر  │ │ سعر  │               │
│ │[أضف] │ │[أضف] │               │
│ └──────┘ └──────┘  × 4 صفوف     │
├─────────────────────────────────┤
│ التذييل                         │
└─────────────────────────────────┘

درج "تصفية" (يُفتح من يسار الشاشة، عكس قائمة الموقع):
┌───────────────────────┐
│ تصفية المنتجات  مسح ✕ │
├───────────────────────┤
│ التوصيل والإهداء       │
│ ☐ متوفر للتوصيل اليوم (7)
│ ☐ يصلح هدية       (6) │
│ المناسبة               │
│ ☐ العيد (6) ☐ الزواج…  │
│ السعر                  │
│ ◉ كل الأسعار           │
│ ○ أقل من 100 ○ 100–200 │
│ ○ أكثر من 200          │
├───────────────────────┤
│ [مسح الكل][عرض 5 منتجات]│ ← ثابت أسفل الدرج
└───────────────────────┘

لا توجد نتائج:
┌─────────────────────────────────┐
│             (🔍)                │
│  لا توجد منتجات تطابق اختيارك   │
│ جرّب إزالة بعض الفلاتر أو راسلنا │
│ [مسح الفلاتر] [اسألنا على واتساب]│
└─────────────────────────────────┘
```

**على التابلت (768px فأكثر):** الفقرة التعريفية كاملة بلا "اقرأ المزيد". الزران والعدد في صف واحد، والشبكة 3 أعمدة، والفلاتر تبقى درجاً.

**على الحاسوب (1024px فأكثر):**
- الفلاتر **عمود جانبي ثابت أثناء التمرير** (يمين الشاشة) بدل الدرج، فيختفي زر "تصفية".
- شريط الأدوات: العدد يميناً، و"ترتيب: [قائمة]" يساراً كقائمة ظاهرة.
- الشبكة 3 أعمدة بجانب الفلاتر.

**السلوك:** الفلترة فورية مع كل اختيار (لا زر "تطبيق" على الحاسوب). داخل مجموعة المناسبة الاختيار "أو" (العيد أو الزواج)، وبين المجموعات "و" (العيد و يصلح هدية و أقل من 100). الترتيب: الأكثر طلباً (الافتراضي)، السعر تصاعدياً، السعر تنازلياً، الأحدث.

### لماذا هذا الترتيب يرفع التحويل؟

| # | العنصر | السبب |
|---|---|---|
| 1 | **عنوان وفقرة قصيرة، تُطوى في الجوال** | الفقرة تخدم Google (الكلمة الرئيسية للتصنيف في نص ظاهر) وتطمئن الزائر بسطرين، لكنها لا تدفع المنتجات تحت الطيّ في الجوال. النص كاملاً في HTML فلا يخسر SEO شيئاً |
| 2 | **"تصفية" و"ترتيب" زرّان متساويان فوق الشبكة مباشرة** | في الجوال الإبهام يصل إليهما بسهولة، ولا يأخذان أكثر من سطر. "ترتيب" قائمة أصلية تفتح منتقي الجوال المألوف بدل نافذة مخصصة |
| 3 | **"متوفر للتوصيل اليوم" و"يصلح هدية" أول الفلاتر** | هما أقوى نيتين عند زائر متجر حلويات: "أحتاجها اليوم" و"أبيها هدية". وضعهما أولاً يختصر الطريق لأكثر الزوار استعجالاً، وهم الأعلى تحويلاً |
| 4 | **المناسبة قبل السعر** | الشراء هنا يبدأ بالمناسبة (عيد، زواج، مولود) لا بالميزانية. وعدد المنتجات بجانب كل خيار يمنع النقر على خيار فارغ |
| 5 | **فلترة فورية + عدد حي + رقائق قابلة للإزالة** | الزائر يرى أثر كل اختيار فوراً ("عرض 2 من 8")، ويتراجع عن أي فلتر بنقرة دون فتح الدرج مرة أخرى |
| 6 | **"الأكثر طلباً" ترتيباً افتراضياً** | دليل اجتماعي: أول ما يراه هو ما يشتريه الناس فعلاً، وهو غالباً الأعلى تحويلاً |
| 7 | **نفس بطاقة الرئيسية مع زر "أضف للسلة"** | تجربة متسقة، والشراء ممكن من الشبكة دون فتح المنتج. وأُضيف سطر "توصيل اليوم / يُطلب قبل يوم" ليفهم الزائر سبب ظهور المنتج أو اختفائه عند الفلترة |
| 8 | **حالة "لا توجد نتائج" بمخرجين** | بدل صفحة فارغة تنهي الزيارة: زر يمسح الفلاتر ويعيد كل المنتجات، ورابط واتساب لمن يريد طلباً خاصاً لا يوجد في الشبكة |
| 9 | **الدرج من الجهة المقابلة لقائمة الموقع** | حتى لا يختلط على الزائر "قائمة الأقسام" و"التصفية"، وزر "عرض N منتجات" ثابت أسفل الدرج يغلقه ويؤكد النتيجة |

> **ملاحظة SEO:** في المعاينة دمجنا المعمول والتمور في صفحة واحدة لتجربة القالب بثمانية منتجات. في المتجر الفعلي يبقيان **تصنيفين منفصلين** حسب `05-content-seo/keyword-map.md` (C2 `maamoul` بكلمة "بوكس معمول"، وC3 `stuffed-dates` بكلمة "تمور محشية")، ولكل منهما فقرته التعريفية، بالقالب نفسه.

**على التابلت (768px فأكثر):** عمودان، المعرض يميناً **ويبقى ثابتاً أثناء التمرير** (sticky)، والمعلومات والخيارات يساراً. شريط الشراء يبقى ثابتاً أسفل الشاشة.

**على الحاسوب (1024px فأكثر):**
- العمودان نفسهما بمسافة أوسع.
- شريط الشراء يعود لمكانه الطبيعي تحت الخيارات (لا يكون ثابتاً)، لأن العمود كله ظاهر.
- المنتجات المقترحة 4 أعمدة.

### لماذا هذا الترتيب يرفع التحويل؟

| # | العنصر | السبب |
|---|---|---|
| 1 | **صور كبيرة أولاً، 4 زوايا** | الحلويات تُشترى بالعين. صورة "مغلق للإهداء" تبيع للمُهدي، وصورة "الحشوة" تبيع للمستهلك، وصورة "الصينية" تبيع لصاحب المناسبة |
| 2 | **التقييم والتوفر بجانب الاسم** | الدليل الاجتماعي قبل السعر يجعل السعر أسهل قبولاً. و"يُحضَّر يوم التوصيل" ميزة لا مجرد حالة مخزون |
| 3 | **السعر شامل الضريبة + التقسيط** | الشفافية تمنع المفاجأة في الدفع، وهي من أكبر أسباب ترك السلة. وعرض قسط تابي يخفّض "الألم" في البوكسات الكبيرة |
| 4 | **الخيارات بأسعارها الظاهرة** | يرى العميل فرق السعر قبل الاختيار، والإجمالي يتحدث فوراً في زر الشراء. هذا يرفع متوسط قيمة الطلب: الترقية للتغليف الفاخر وحجم 36 قطعة |
| 5 | **رسالة الإهداء والموعد في الصفحة** | يجيبان عن سؤالي المُهدي ("هل أقدر أكتب له؟" و"هل يوصل يوم المناسبة؟") في لحظة القرار نفسها |
| 6 | **زر ثابت أسفل الشاشة في الجوال** | مهما نزل الزائر ليقرأ المكونات أو الآراء، يبقى الشراء على بعد نقرة، مع الإجمالي الحالي |
| 7 | **شارات الثقة وطرق الدفع تحت الزر مباشرة** | تزيل آخر تردد في اللحظة التي يفكر فيها بالضغط |
| 8 | **الأوصاف في أكورديون** | الحساسية والصلاحية مهمة قانونياً وللثقة، لكنها لا تُدفع فوق الخيارات. الأكورديون يبقيها قريبة دون إطالة الصفحة |
| 9 | **منتجات مقترحة** | فرصة البيع الإضافي: تمر أو بقلاوة مع المعمول |

## 4. ملاحظات التطبيق على سلة (مهم قبل الاعتماد)

هذه المعاينة **تصوّر الشكل المستهدف**. في سلة يولّد القالب HTML بنفسه، فيُطبق التصميم بإعدادات القالب وCSS المخصص (باقة برو + نطاق خاص، حسب `04-store-setup/salla-plans-verification.md` القسمين 3 و7).

| عنصر في المعاينة | كيف يتحقق في سلة | الحالة |
|---|---|---|
| شريط الإعلان العلوي | ميزة "الشريط الإعلاني" في المتجر أو القالب | ⚠ يُتحقق من مكانه في القالب المختار |
| البانر الرئيسي | عنصر بانر أو سلايدر من محرر الصفحة الرئيسية. **العنوان والزر غالباً جزء من الصورة نفسها**، فيُصمَّم البانر صورةً بمقاسي الجوال والحاسوب | ⚠ يُتحقق هل يدعم القالب نصاً وزراً فوق الصورة |
| الأكثر طلباً | عنصر "منتجات" مرتبط بتصنيف أو اختيار يدوي | ✔ متوقع في رائد |
| المناسبات | تصنيفات أو "روابط سريعة" بصور أيقونات المناسبات | ⚠ شكل البطاقات يُضبط بـ CSS |
| المزايا | عنصر "مزايا المتجر" إن وفّره القالب | ⚠ |
| آراء العملاء | عنصر "آراء العملاء" أو تقييمات سلة | ⚠ |
| الأسئلة الشائعة في الرئيسية | قد لا يوجد عنصر جاهز لها. البديل: صفحة "الأسئلة الشائعة" مستقلة مع رابط لها، أو حقنها بـ JS المخصص | ⚠ |
| صفحة التصنيف: الترتيب وعدد المنتجات | يولّدها القالب. خيارات الترتيب المتاحة تحددها سلة/القالب، وقد لا تطابق الأربعة في المعاينة | ⚠ يُتحقق من القالب |
| صفحة التصنيف: الفلاتر | فلترة السعر شائعة في قوالب سلة. فلاتر "المناسبة" و"يصلح هدية" و"التوصيل اليوم" **ليست حقولاً قياسية**؛ البديل: تصنيفات فرعية (المناسبات C9) أو وسوم، أو روابط سريعة أعلى التصنيف | ⚠ يُتحقق مما يدعمه القالب قبل الوعد بها |
| فقرة التصنيف التعريفية | حقل وصف التصنيف في سلة. الطيّ في الجوال بـ CSS على عنصر القالب | ⚠ مكان الوصف يختلف حسب القالب |
| سطر "توصيل اليوم" على البطاقة | غير قياسي. يمكن تقريبه بشارة/وسم منتج، أو حذفه | ⚠ |
| عدد القطع والتغليف | **خيارات المنتج** (المنتجات ← الخيارات) | ✔ مسار موثّق |
| رسالة الإهداء | خيار منتج نصي، أو **خيار طلب** في السلة، أو "نظام الإهداء" | ✔ / ⚠ حسب الباقة |
| **تاريخ وفترة التوصيل** | **خيار طلب "موعد" في السلة** (باقة برو). أي أنه يظهر في السلة **لا في صفحة المنتج** | ✔ مؤكد، ويعني أن مكانه في المتجر الحي يختلف عن المعاينة |
| زر الشراء الثابت في الجوال | بعض القوالب توفّره. وإلا يُبنى بـ CSS (`position: sticky/fixed`) على زر القالب | ⚠ يُفحص على القالب |
| التقسيط (تابي) | تُظهره سلة تلقائياً عند تفعيل تابي | ✔ يعتمد على تفعيل العميل |
| شعارات الدفع والسجل التجاري | التذييل في سلة يعرض طرق الدفع المفعّلة والسجل والرقم الضريبي من بيانات المتجر | ⚠ يُتحقق من القالب |

> **نتيجة مهمة للعرض على العميل:** نقول له إن "موعد التوصيل" سيُختار في **السلة** قبل الدفع، لا في صفحة المنتج. على الحاسوب يرفع هذا زر "أضف للسلة" للأعلى، فيظهر في الشاشة الأولى.
