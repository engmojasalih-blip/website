# معاينة التصميم (Demo) — "دار الحلا"

> نموذج تصميم **تجريبي** لمتجر حلويات على سلة، يُعرض على العميل ليتخيل الشكل النهائي، ويصلح نموذج أعمال.
> الاسم والأسعار والصور والآراء كلها **توضيحية**، والصفحات الثلاث تحمل هذا التنبيه أعلاها وفي التذييل.

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `category.html` | صفحة تصنيف "المعمول والتمور": 8 منتجات، ترتيب وفلترة فعليان، ودرج تصفية في الجوال |
| `product.html` | صفحة منتج "بوكس معمول فاخر" |
| `styles.css` | كل التنسيقات. **الألوان والخطوط والمسافات متغيرات في `:root` (القسم 1)** |
| `app.js` | سكربت خفيف بلا مكتبات: قائمة الجوال، وعداد السلة ورسالة التأكيد، والمعرض، وحساب السعر حسب الخيارات، وعداد رسالة الإهداء، وترتيب التصنيف وفلترته ودرج التصفية |
| `img/*.svg` | رسومات توضيحية محلية للمنتجات والبانر والأيقونة. **لا صور من الإنترنت ولا روابط خارجية للصور** |

الاعتماد الخارجي الوحيد هو خط **IBM Plex Sans Arabic** من Google Fonts. بدون إنترنت تعمل الصفحة بخط النظام الاحتياطي.

## طريقة الفتح

**الأسهل:** افتح `index.html` بالنقر المزدوج في أي متصفح حديث (Chrome، Edge، Safari). كل الروابط والصور نسبية فتعمل مباشرة.

**بخادم محلي** (مفيد لعرضه من الجوال على الشبكة نفسها):
```bash
# من مجلد المشروع
python -m http.server 5173 --directory 02-design/preview
# ثم افتح http://localhost:5173
```
يوجد إعداد جاهز بالاسم نفسه (`design-preview`) في `.claude/launch.json`.

**لتجربة مقاسات الجوال:** أدوات المطور (F12) ← وضع الجهاز ← 360 / 768 / 1280.

## ما الذي يجربه العميل

- **الجوال:** زر القائمة (ثلاثة خطوط) يفتح درجاً جانبياً يُغلق بـ Esc أو بالنقر خارجه.
- **"أضف للسلة"** يزيد عداد السلة ويُظهر رسالة تأكيد. العداد محفوظ بين الصفحات في المتصفح نفسه.
- **الرحلة الكاملة:** من القائمة أو التذييل ("المعمول" أو "التمور المحشية") إلى صفحة التصنيف، ثم بطاقة "بوكس معمول فاخر" إلى صفحة المنتج، والعودة بمسار التصفح.
- **صفحة التصنيف:**
  - الترتيب: الأكثر طلباً، والسعر تصاعدياً وتنازلياً، والأحدث.
  - الفلاتر: متوفر للتوصيل اليوم، ويصلح هدية، والمناسبة، والسعر. العدد يتحدث فوراً، وكل فلتر مفعّل يظهر رقاقة تُزال بنقرة.
  - في الجوال والتابلت: زر "تصفية" يفتح درجاً (يُغلق بـ Esc أو بالنقر خارجه أو بزر "عرض N منتجات")، و"ترتيب" يفتح منتقي الجوال الأصلي. على الحاسوب الفلاتر عمود جانبي.
  - جرّب "الزواج" + "أقل من 100 ر.س" لرؤية حالة "لا توجد نتائج" وزر مسح الفلاتر.
  - الفقرة التعريفية مطوية لسطرين في الجوال، و"اقرأ المزيد" يفتحها.
- **صفحة المنتج:**
  - تغيير عدد القطع والتغليف والكمية يحدّث السعر وقسط تابي وإجمالي الزر فوراً.
  - المصغّرات تبدّل الصورة الرئيسية.
  - في الجوال يبقى زر الشراء **ثابتاً أسفل الشاشة**.
- الروابط التي لا تقابلها صفحة في النموذج (السياسات، والتصنيفات الأخرى، والمنتجات غير بوكس المعمول، وواتساب) تُظهر رسالة توضيحية بدل أن تنقل لصفحة فارغة.

## من المعاينة إلى سلة: ما يُنقل وما لا يُنقل

**الفكرة الأساسية:** سلة تولّد HTML الصفحات بنفسها من القالب (رائد أو غيره). لذلك **لا يُرفع `index.html` ولا `category.html` ولا `product.html` إلى المتجر**. الذي يُنقل هو *القرارات البصرية*، ويُعاد كتابتها على **محددات (selectors) القالب الفعلي** في `03-theme-css/custom.css`.

### يُنقل إلى `03-theme-css/custom.css` (بعد اعتماد التصميم ومعرفة القالب)

| من `styles.css` | كيف يُنقل |
|---|---|
| **القسم 1: المتغيرات `:root`** | يُنقل كما هو تقريباً. هو "مصدر الحقيقة" للهوية |
| أنماط الأزرار (`.btn--cta` وحالاتها) | تُطبق على أزرار القالب (زر الإضافة للسلة، وزر الشراء) |
| بطاقة المنتج (الزوايا، والظل، ونسبة الصورة 1:1، وقص الاسم لسطرين، وموضع الشارات) | تُطبق على عنصر بطاقة المنتج في القالب |
| الشارات (الخصم، والجديد، والأكثر طلباً) | على شارات القالب. شارة الخصم تولّدها سلة تلقائياً |
| الخيارات (الرقائق وبطاقات التغليف) | على عناصر "خيارات المنتج" في القالب، **دون إخفاء أي حقل وظيفي** |
| الأكورديون والأسئلة الشائعة | إن وفّر القالب عنصراً مشابهاً |
| شريط الشراء الثابت في الجوال | `position: fixed/sticky` على حاوية زر القالب، إن لم يوفّره القالب |
| صفحة التصنيف (القسم 8ب) | شكل شريط الأدوات ودرج الفلاتر والرقائق وحالة "لا توجد نتائج" وطيّ الوصف في الجوال، على عناصر القالب. **الترتيب والفلترة نفسها يولّدها القالب**، وفلاتر المناسبة/الهدية/التوصيل اليوم غير قياسية (راجع `../wireframes.md` القسم 4) |
| الخط | `--font-base`، أو اختياره من إعدادات القالب إن كان متاحاً |

### يبقى معاينة فقط (لا يُنقل)

| العنصر | السبب |
|---|---|
| ملفات HTML كاملة | سلة تولّد البنية بنفسها |
| `app.js` | السلة والسعر والخيارات والمعرض والبحث وترتيب التصنيف وفلترته تديرها سلة. قد تُستفاد فكرة صغيرة فقط (مثل عداد رسالة الإهداء) في `03-theme-css/custom.js` إن لم يوفّرها القالب |
| رسومات `img/*.svg` | تُستبدل **بصور حقيقية للمنتجات** من العميل (JPG مضغوطة، مربعة، بعرض 1200px على الأقل) |
| أسماء الكلاسات (`.product-card` وغيرها) | كلاسات المعاينة، تُستبدل بكلاسات القالب الفعلية |
| شريط "نموذج تصميم تجريبي" وشارات "رأي نموذجي" | للعرض فقط |
| حقل تاريخ التوصيل داخل صفحة المنتج | في سلة يكون **خيار طلب "موعد" في السلة** (باقة برو)، لا في صفحة المنتج |
| شارات الدفع النصية (مدى، Apple Pay...) | سلة تعرض شعارات الدفع الرسمية حسب الوسائل المفعّلة |

### شروط قبل كتابة `custom.css` (لم يُكتب بعد عمداً)

1. **اعتماد العميل** لهذا التصميم أو تعديلاته.
2. **باقة سلة برو أو سبيشل + نطاق خاص.** خانة CSS المخصص لا تعمل بدونهما (مؤكد، `04-store-setup/salla-plans-verification.md` القسم 3).
3. **معرفة القالب المختار ونسخته** (قرار D-01)، وفحص محدداته على المتجر الفعلي بأدوات المطور، بدل تخمينها.
4. **هوية العميل** (الشعار والألوان والخط)، لتحديث متغيرات `:root` وإعادة حساب التباين.

مكان اللصق لاحقاً في لوحة سلة: **المتجر وقنوات البيع ← تصميم المتجر ← تخصيص النسخة ← تبويب (تخصيص متقدم)**.

## تغيير الهوية في المعاينة نفسها

- **الألوان:** عدّل `--color-primary` و`--color-accent` و`--color-cta` وبقية المتغيرات في أول `styles.css`، ثم تحقق من نسب التباين (الجدول في `../style-guide.md` القسم 2).
- **الخط:** غيّر رابط Google Fonts في `<head>` بالصفحات الثلاث، وقيمة `--font-base`.
- **الصور:** ضع صوراً بنفس أسماء ملفات `img/` أو حدّث المسارات. البطاقات تقص أي صورة إلى مربع تلقائياً.

## ما تم التحقق منه

- HTML سليم: الوسوم مغلقة، ولا معرّفات (id) مكررة، وكل `label` مرتبط بحقله، ولكل صورة نص بديل.
- الروابط بين الصفحات الثلاث والروابط الداخلية (`#best-sellers`، `#occasions`، `#faq`، `#reviews`) تعمل، وكل مسارات الصور موجودة.
- لا أخطاء JavaScript في الكونسول، وجُرّبت: الإضافة للسلة، وحساب السعر، والمعرض، وعداد الرسالة، والقائمة.
- لا تمرير أفقي على عرض 360px. وفُحص العرض بصرياً على 360 و768 و1280px.
- صفحة التصنيف: كل أنواع الترتيب الأربعة تعطي الترتيب الصحيح، والفلاتر (منفردة ومجتمعة) تطابق بيانات المنتجات، وحالة "لا توجد نتائج" تظهر وتُمسح، والدرج يفتح ويُغلق (زر الإغلاق، والخلفية، وEsc) ويعيد التركيز لزر "تصفية"، ولا تمرير أفقي على 360 و768 و1280.
