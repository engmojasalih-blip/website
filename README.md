# متجر حلويات إلكتروني على منصة سلة

مشروع إنشاء وتجهيز متجر حلويات سعودي على منصة **سلة** من الصفر حتى التشغيل: تصميم متجاوب، CSS مخصص لقالب رائد، إعدادات المتجر، 5–10 منتجات، SEO، اختبار، وإطلاق وتسليم.

> **الحالة:** التحضير المسبق مكتمل لكل المراحل، وبانتظار إجابات العميل. التفاصيل في [`01-analysis/status-report.md`](01-analysis/status-report.md).

## نموذج التصميم

**المعاينة الحية:** https://engmojasalih-blip.github.io/website/ (تُنشر من فرع `gh-pages`)

نموذج تجريبي باسم "دار الحلا" (الأسماء والأسعار والصور توضيحية) في [`02-design/preview/`](02-design/preview/): الصفحة الرئيسية، صفحة التصنيف، وصفحة المنتج. افتح `index.html` في المتصفح.

## هيكل المشروع

| المجلد | المحتوى | المسؤول |
|---|---|---|
| `01-analysis/` | استبيان العميل (Markdown وWord)، خطة التنفيذ، الجدول الزمني، تقرير الحالة | مدير المشروع |
| `02-design/` | دليل الأسلوب، الهياكل، معاينة HTML | مصمم UI/UX |
| `03-theme-css/` | CSS مخصص لقالب رائد وخريطة المحددات | مصمم UI/UX |
| `04-store-setup/` | التحقق من باقات سلة، قائمة التجهيز، التوصيل والدفع، التتبع، قالب استيراد المنتجات، جدول أعمال الجلسة الأولى | مطور سلة |
| `05-content-seo/` | الكلمات المفتاحية، المنافسون، خريطة الكلمات، مسودات الصفحات والسياسات | كاتب المحتوى وSEO |

## ملاحظات

- مسودات السياسات ليست استشارة قانونية، ويعتمدها صاحب المتجر قبل النشر.
- لا يحتوي المستودع على كلمات مرور أو بيانات بنكية أو وثائق رسمية.
